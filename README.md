## Abstract

High-rate dense perception in dynamic environments is limited by the low
update rate of RGB cameras, as rapid scene changes can occur between frames.
LiFR v2 introduces a unified propagation–completion–memory framework for
causal anytime and streaming dense prediction from an RGB keyframe and events.

## Highlights

- Causal anytime and streaming dense prediction
- Event-Guided Completion Module (EGCM)
- History Retrieval Module (HRM)
- Semantic segmentation, monocular depth, and multi-task prediction
- SHF-Emerge benchmark for rapid emergence and disocclusion
